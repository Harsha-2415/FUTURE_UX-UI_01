# 💎 ROYAL COLLECTIONS – Jewellery Store Reservation App

## 📖 Overview
ROYAL COLLECTIONS is a premium jewellery reservation mobile application designed to provide customers with a seamless showroom booking experience. Users can browse exclusive jewellery collections, reserve their preferred designs, and schedule a showroom visit before making a purchase.

## ✨ Features
- Luxury Black & Gold UI
- Splash Screen
- User Authentication
- Home Dashboard
- Jewellery Categories
- Featured Collections
- Search Jewellery
- Showroom Visit Booking
- Date & Time Slot Selection
- Booking Confirmation

## 📱 Screens
- Splash Screen
- Login Screen
- Home Screen
- Book Your Visit
- Booking Confirmation

## 🎨 Design System

### Colors
- Gold (#D4AF37)
- Black (#121212)
- White (#FFFFFF)
- Light Cream (#FFF8F0)

### Typography
- Poppins
- Playfair Display
